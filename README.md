## 서비스 개발 및 최적화: 하이브리드 클러스터 대응 HRM 앱
### 1. 프로젝트 개요
- 설명: 온프레미스(OKD)와 클라우드(K3s) 멀티 클러스터 환경에서 유연하게 동작하도록 설계된 PHP 기반 인사관리 애플리케이션입니다.

- 핵심 목표: 물리적으로 떨어진 환경 간의 네트워크 지연(Latency) 문제를 코드 레벨에서 극복하고 데이터 무결성을 유지하는 서비스를 구현하는 것입니다.

### 2. 주요 구현 사항: 하이브리드 환경 대응 로직
DB 접속 객체 분리 (Read/Write Splitting)

하이브리드 인프라의 특성상 발생하는 네트워크 병목 현상을 해결하기 위해 애플리케이션 코드 레벨에서 DB 연결을 분리했습니다.

쓰기 작업: 데이터의 원본(Master)이 있는 온프레미스 MariaDB로 연결하여 데이터 정합성을 보장합니다.

읽기 작업: AWS 환경에서는 앱과 물리적으로 가까운 곳에 복제된 Aurora MySQL(Slave)을 조회하게 하여 응답 속도를 최적화했습니다.

이기종 스토리지 최적화 전략

데이터 업로드: 프로필 사진 등 파일 저장 시, VPN을 통해 온프레미스 MinIO를 원본 저장소로 사용하여 데이터의 일관성을 유지합니다.

데이터 조회: 환경 변수를 감지하여 AWS 환경일 경우 S3의 URL을 반환하게 함으로써, 클라우드 사용자에게 빠른 이미지 로딩 속도를 제공합니다.

### 3. 기술적 해결 및 성과
환경 인지형 서비스 설계

CLUSTER_ENV 환경 변수를 활용해 현재 운영 중인 인프라(AWS vs ON-PREM)를 앱이 스스로 인식하도록 했습니다.

이를 통해 로그인 화면에 현재 접속 중인 클러스터 정보를 표시하는 등 운영 편의성을 높였습니다.

Stateless 아키텍처 구현

세션 정보를 데이터베이스에서 관리하고 파일 저장을 외부 오브젝트 스토리지로 완전히 분리했습니다.

이를 통해 온프레미스 장애로 인한 클러스터 간 서비스 전환(Failover) 시에도 사용자가 끊김 없는 서비스를 경험할 수 있도록 설계했습니다.
